# React Vite Google Sheets User Listing

This project is a React app bootstrapped with Vite. It fetches and displays user status and details from a Google Sheet, as per the provided sample sheet structure.

## Getting Started

1. **Install dependencies:**
   ```sh
   npm install
   ```
2. **Start the development server:**
   ```sh
   npm run dev
   ```

## Features
- Reads user data from a Google Sheet (to be configured)
- Displays a listing of user status and details
- Modern, clean UI
